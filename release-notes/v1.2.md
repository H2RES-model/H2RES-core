## Version 1.2

**Description:**  
Third public release of H2RES. Version 1.2 introduces a rolling-horizon execution pathway while preserving the same sector-coupled physical logic used in earlier releases.

**Model scope:**  
Single-system planning model that can be solved either as a full-horizon problem or through rolling-horizon windows.

**Key features**
- All v1.1 energy-system modules retained
- Rolling-horizon execution mode
- Explicit temporal controls through `years` and `window`
- Carry-over logic for cumulative investment decisions across planning windows
- Auxiliary overflow investment variable for annual expansion flexibility
- Hydro spillage cost represented in the objective
- Extended temporal scenario management for long-horizon studies

**Main implementation changes**
- New active entrypoint based on `main_rolling_horizon_v3.py`
- Execution routing through `scripts/modeling_approaches.py`
- Support for both standard full-horizon execution and rolling-horizon execution
- Reorganized workflow around time-horizon management and sequential solves

**Recommended use:**  
Use v1.2 when the research problem requires rolling-horizon analysis, staged investment decisions, or comparison between full-horizon and sequential solution strategies.
