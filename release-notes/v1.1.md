**Description:**  
Second public release of H2RES. Version 1.1 preserves the original single-system logic of v1.0 while improving input preprocessing and extending adequacy-relaxation logic through explicit unmet-service variables in electricity and heat blocks.

**Model scope:**  
Single-system sector-coupled planning model with the same main architecture as v1.0, but a more maintainable and transparent input pipeline.

**Key features**
- All core v1.0 modules retained
- Explicit unmet-service variables for electricity and heat adequacy relaxation
- Explicit scarcity-penalty structure in the objective function
- Separate annual CAPEX trajectories for key flexible technologies
- Improved traceability between raw inputs and model parameters
- Continued support for reserve, hydrogen, heat, and storage modules

**Main implementation changes**
- Migration from the earlier input style to direct CSV/XLSX-based preprocessing
- Cleaner hand-off between input files and optimization parameters
- Stronger transparency for scenario preparation and debugging
- Better practical usability for adapting the model to new datasets

**Recommended use:**  
Use v1.1 when you want the original H2RES logic with a cleaner and more accessible data-engineering workflow than v1.0.
